# Fixed Point

Реализация арифметики чисел с фиксированной точкой на C++.

Программа работает с числами в формате `A.B`, где общее количество бит равно `A + B`, а `B` бит используются для хранения дробной части.

Числа передаются программе в виде шестнадцатеричного битового представления. Арифметические операции выполняются вручную с использованием целочисленной и побитовой арифметики.

Реализованы:

- сложение
- вычитание
- умножение
- деление
- четыре режима округления
- обработка переполнения
- отрицательные числа в дополнительном коде
- вывод результата с тремя знаками после точки

## Формат fixed-point

Число задается в формате:

```text
A.B
```

где:

```text
A - количество бит целой части вместе со знаком
B - количество бит дробной части
```

Общая ширина числа:

```text
A + B
```

Например:

```text
8.8
```

означает 16-битное fixed-point число:

```text
8 бит целой части
8 бит дробной части
```

Фактическое значение определяется как:

```text
value = raw / 2^B
```

где `raw` является знаковым целым числом, хранящимся в дополнительном коде.

## Пример представления

Рассмотрим формат:

```text
8.8
```

В нем:

```text
B = 8
2^B = 256
```

Число:

```text
1.0
```

представляется как:

```text
1.0 * 256 = 256
```

или:

```text
0x0100
```

Число:

```text
1.5
```

представляется как:

```text
1.5 * 256 = 384
```

или:

```text
0x0180
```

Число:

```text
2.25
```

представляется как:

```text
2.25 * 256 = 576
```

или:

```text
0x0240
```

## Хранение отрицательных чисел

Отрицательные значения хранятся в дополнительном коде.

Для определения знака используется старший бит числа:

```text
A + B - 1
```

Если он установлен, битовая последовательность интерпретируется как отрицательное число.

Например, для 16-битного формата значение:

```text
0xFF00
```

соответствует:

```text
-1.0
```

при формате:

```text
8.8
```

## Поддерживаемые операции

Программа поддерживает четыре арифметические операции:

```text
+
-
*
/
```

Все операции выполняются над числами одного и того же формата `A.B`.

## Сложение

Сложение выполняется непосредственно над внутренними целочисленными представлениями:

```text
raw_result = raw_a + raw_b
```

После этого результат приводится к допустимой разрядности формата.

Пример:

```text
1.5 + 2.25 = 3.75
```

Для формата `8.8`:

```text
1.5  = 0x0180
2.25 = 0x0240
3.75 = 0x03C0
```

Запуск:

```bash
<program> 8.8 1 + 0180 0240
```

Результат:

```text
3.750
```

## Вычитание

Вычитание также выполняется непосредственно над внутренними представлениями:

```text
raw_result = raw_a - raw_b
```

Пример:

```bash
<program> 8.8 1 - 0300 0100
```

Значения:

```text
0x0300 = 3.0
0x0100 = 1.0
```

Результат:

```text
2.000
```

## Умножение

При умножении двух fixed-point чисел количество дробных бит временно удваивается.

Если:

```text
a = raw_a / 2^B
b = raw_b / 2^B
```

то произведение имеет вид:

```text
a * b = (raw_a * raw_b) / 2^(2B)
```

Для возвращения результата к исходному формату необходимо разделить произведение на:

```text
2^B
```

В программе выполняется:

```text
raw_result = round(raw_a * raw_b / 2^B)
```

При этом используется выбранный режим округления.

Пример:

```text
1.5 * 2.0 = 3.0
```

Для формата `8.8`:

```bash
<program> 8.8 1 '*' 0180 0200
```

Результат:

```text
3.000
```

В некоторых командных оболочках символ `*` необходимо заключать в кавычки.

## Деление

Для сохранения `B` дробных бит перед делением делимое предварительно сдвигается влево:

```text
raw_a << B
```

После этого выполняется:

```text
raw_result = round((raw_a * 2^B) / raw_b)
```

Пример:

```text
3.0 / 2.0 = 1.5
```

Для формата `8.8`:

```bash
<program> 8.8 1 / 0300 0200
```

Результат:

```text
1.500
```

## Деление на ноль

Если второй операнд при делении равен нулю, программа выводит:

```text
div_by_zero
```

и завершает выполнение.

Пример:

```bash
<program> 8.8 1 / 0100 0000
```

Результат:

```text
div_by_zero
```

## Режимы округления

Программа поддерживает четыре режима округления.

| Код | Режим |
|---:|---|
| `0` | к нулю |
| `1` | к ближайшему, при равенстве к четному |
| `2` | к положительной бесконечности |
| `3` | к отрицательной бесконечности |

Режим округления передается вторым аргументом командной строки.

## Округление к нулю

Код:

```text
0
```

Дробная часть результата просто отбрасывается.

Для положительных чисел значение уменьшается по модулю.

Для отрицательных чисел значение также округляется в сторону нуля.

Пример:

```text
1.9 -> 1
-1.9 -> -1
```

## Округление к ближайшему четному

Код:

```text
1
```

Используется округление:

```text
round to nearest, ties to even
```

Результат округляется к ближайшему представимому значению.

Если число находится точно посередине между двумя возможными значениями, выбирается значение с четным младшим битом.

Пример:

```text
2.5 -> 2
3.5 -> 4
```

Такой способ позволяет уменьшить систематическую ошибку при большом количестве округлений.

## Округление к положительной бесконечности

Код:

```text
2
```

Результат округляется в сторону:

```text
+infinity
```

Для положительного числа выполняется округление вверх.

Для отрицательного числа результат округляется в сторону нуля.

## Округление к отрицательной бесконечности

Код:

```text
3
```

Результат округляется в сторону:

```text
-infinity
```

Для отрицательного числа выполняется округление вниз.

Для положительного числа результат округляется в сторону нуля.

## Переполнение

После выполнения арифметической операции результат приводится к разрядности:

```text
A + B
```

Для этого используется циклическое переполнение, соответствующее поведению знакового числа в дополнительном коде.

Значение сначала приводится по модулю:

```text
2^(A + B)
```

После этого старший бит интерпретируется как знак.

Таким образом, переполнение не приводит к насыщению минимальным или максимальным значением.

Вместо этого значение переходит через границу диапазона.

Это соответствует обычному wrap-around поведению фиксированного битового представления.

## Маскирование входного значения

При создании числа учитываются только младшие:

```text
A + B
```

бит входного шестнадцатеричного значения.

Если формат занимает меньше 32 бит, остальные биты отбрасываются.

Например, для формата:

```text
4.4
```

используются только:

```text
8 бит
```

входного значения.

## Формат входных данных

Общий формат запуска:

```bash
<program> <A.B> <rounding_mode> ...
```

Например:

```bash
<program> 8.8 1 ...
```

означает:

```text
формат: 8.8
округление: round to nearest, ties to even
```

## Вывод одного числа

Для вывода одного fixed-point значения используется:

```bash
<program> <A.B> <rounding_mode> <hex_value>
```

Пример:

```bash
<program> 8.8 1 0180
```

Значение:

```text
0x0180
```

в формате:

```text
8.8
```

соответствует:

```text
1.5
```

Результат:

```text
1.500
```

## Выполнение операции

Общий формат:

```bash
<program> <A.B> <rounding_mode> <operation> <value1> <value2>
```

Например:

```bash
<program> 8.8 1 + 0180 0240
```

Выполняется:

```text
1.5 + 2.25
```

Результат:

```text
3.750
```

## Вывод результата

Результат выводится в десятичной системе с тремя знаками после точки.

Формат:

```text
integer.fraction
```

Например:

```text
0.500
1.000
3.750
-2.125
```

Для формирования вывода внутреннее fixed-point значение масштабируется на:

```text
1000
```

после чего округляется в соответствии с выбранным режимом.

Поэтому выбранный режим округления влияет не только на результаты умножения и деления, но и на преобразование значения в десятичную строку.

## Класс FixedPoint

Основная логика программы находится в классе:

```cpp
class FixedPoint
```

Класс хранит:

```cpp
int32_t raw;
int A;
int B;
```

`raw` содержит целочисленное представление fixed-point числа.

`A` и `B` описывают его формат.

## Метод round

Функция:

```cpp
round(...)
```

выполняет целочисленное деление с учетом выбранного режима округления.

Она используется:

- при умножении
- при делении
- при формировании десятичного вывода

Функция анализирует:

```text
частное
остаток
знак результата
режим округления
```

Для режима nearest-even дополнительно проверяется четность младшего бита частного.

## Метод clamp

Функция:

```cpp
clamp(...)
```

приводит результат операции к заданной разрядности.

Размер представления:

```text
A + B
```

Сначала вычисляется остаток по модулю:

```text
2^(A + B)
```

После этого результат интерпретируется как число в дополнительном коде.

## Перегруженные операторы

Для выполнения операций используются перегруженные операторы C++:

```cpp
operator+
operator-
operator*
operator/
```

Это позволяет работать с объектами `FixedPoint` в привычной форме.

Например:

```cpp
FixedPoint result = num1 + num2;
```

или:

```cpp
FixedPoint result = num1 * num2;
```

## Внутренняя арифметика

Хотя само fixed-point число хранится в `int32_t`, промежуточные вычисления выполняются с использованием:

```cpp
int64_t
```

Это позволяет уменьшить риск переполнения во время:

- сложения
- вычитания
- умножения
- масштабирования
- деления

После завершения операции результат снова приводится к исходной разрядности.

## Пример вычисления

Рассмотрим:

```text
1.5 * 2.25
```

в формате:

```text
8.8
```

Первое число:

```text
1.5 * 256 = 384
```

то есть:

```text
0x0180
```

Второе число:

```text
2.25 * 256 = 576
```

то есть:

```text
0x0240
```

При умножении внутренних представлений:

```text
384 * 576 = 221184
```

Так как в произведении присутствуют лишние `B` дробных бит, результат делится на:

```text
2^8 = 256
```

Получаем:

```text
221184 / 256 = 864
```

В обычном представлении:

```text
864 / 256 = 3.375
```

Запуск:

```bash
<program> 8.8 1 '*' 0180 0240
```

Результат:

```text
3.375
```
